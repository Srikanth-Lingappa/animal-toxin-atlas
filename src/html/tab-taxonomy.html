Taxonomic tree of source organisms

How to read this
Built from NCBI's classification for each source organism, domain down to species. Use it to see how toxin coverage, structural data, and disulfide scaffolds are distributed across the animal kingdom — including cases where unrelated lineages (say, a spider and a cone snail) independently evolved the same disulfide scaffold. Long runs of single-child ancestry are compressed into one row, shown as a breadcrumb, so you're not scrolling through a dozen nested clades with nothing else branching off them.
